# SurvArena contributor environment compatibility path
#
# Python:
#   - preferred: CPython 3.11
#   - supported by scripts/setup_env.sh: CPython 3.10, 3.11, and 3.12
#   - package metadata: requires-python >=3.10,<3.13
#
# The primary contributor and CI path uses uv with the committed uv.lock:
#   uv sync --locked
#   uv run --no-sync python -m pytest
#
# This file preserves the pip compatibility install target. It installs from
# pyproject.toml and is not a resolved or lock-equivalent environment. Citable
# benchmark releases use the separately governed canonical Linux/amd64
# environment rather than either developer-machine workflow.
#
# Pip compatibility setup:
#   python3.11 -m venv .venv
#   source .venv/bin/activate
#   python -m pip install --upgrade pip
#   python -m pip install -r requirements.txt
#
# Equivalent compatibility script:
#   PYTHON_BIN=python3.11 ./scripts/setup_env.sh
#
# The default contributor environment includes the foundation dependencies used
# by the manuscript benchmark, including TabPFN and TabICL:
#   python -m pip install -e ".[dev,foundation-tabpfn,foundation-tabarena]"
#   python -m pip install -e ".[foundation]"
#   python -m pip install -e ".[foundation-tabpfn]"
#   python -m pip install -e ".[foundation-mitra]"
#   python -m pip install -e ".[tracking]"
